ATTACK PROGRESSION PROBABILITY REPORT (FEATURE 13)
======================================================================

1. OBJECTIVE
   Convert LSTM-predicted future network states (Feature 12) into P(Infiltration) via the frozen Feature 11 classifier, at horizons K=1,2,3,5.

2. SCIENTIFIC DISTINCTION (Feature 12 vs Feature 13)
   Feature 12 answers: what might the future network state look like? Feature 13 answers: given the predicted future network state, how strongly does the frozen attack classifier associate that future state with Infiltration? This is not MITRE ATT&CK stage prediction, causal attacker-intent prediction, guaranteed early warning, a risk score, or a mitigation decision.

3. PRIMARY RESULT: Full recursive CyberChess pipeline (predicted future state -> frozen classifier)
   DIAGNOSTIC: Oracle future-state diagnostic (ground-truth future state -> frozen classifier; NOT a deployment result)

4. TEST-SET LIMITATION
   The current chronological TEST partition contains no Infiltration samples, so attack-progression detection metrics cannot be established on that partition. Feature 13 is therefore evaluated on the mixed-class VALIDATION partition as a development-stage assessment. A later expanded multi-day evaluation will provide a proper unseen attack-containing test set.
