LSTM WORLD MODEL REPORT (FEATURE 10)
======================================================================

1. OBJECTIVE
   Learn P(S(t+1) | S(t-9), ..., S(t)) - next network-state regression, not attack classification.

2. INPUT REPRESENTATION
   10 consecutive 68-dimensional network states (X_sequences_scaled from Feature 7),
   shape (batch, 10, 68). Target: next_window_features_scaled, shape (batch, 68).

3. WORLD MODEL FORMULATION
   S(t-9:t) -> S(t+1), a 68-dimensional continuous state vector predicted from the preceding 10 states.
   Model type: LSTM-based Network World Model (LSTM temporal network-state dynamics model).

4. ARCHITECTURE
   input_size: 68
   hidden_size: 128
   num_layers: 2
   dropout: 0.2
   Output head: Linear(hidden_size -> input_size) applied to the final LSTM hidden state.

     training configuration was used as-is.

     rate/IAT-style features are harder to predict than count-like features.
   - Single continuous-day capture: generalization to other days/networks is untested.
